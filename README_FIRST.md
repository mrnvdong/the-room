# THE ROOM — Antigravity Handoff Package

This package contains the implementation specification and execution prompts for building THE ROOM.

## How to use

1. Extract this ZIP into an empty project folder.
2. Open that folder in Google Antigravity.
3. Ask the agent:

   **"Read `AGENTS.md` and all files in `spec/` and `prompts/`. Follow the instructions in `AGENTS.md`. Start implementation now. Do not stop at planning. Build and test Phase 0 and Phase 1 first."**

4. Let the agent complete and test the first phase before asking it to continue.

## Package contents

- `AGENTS.md`: Main instructions for the coding agent.
- `spec/MASTER_SPECIFICATION.md`: Full product and technical specification.
- `spec/ROOM_INTERACTIONS.md`: Object-by-object interaction requirements.
- `spec/CONTENT_MODEL.md`: Portfolio content and data model.
- `spec/ACCEPTANCE_TESTS.md`: Functional acceptance checklist.
- `prompts/`: Ready-to-use phase prompts if the agent needs more focused instructions.

## Important

This is a development brief, not an already implemented application. The coding agent must create the source code, assets/placeholders, tests, and deployment configuration in this folder.

Do not let the agent claim a feature is complete unless it runs and has been tested.
