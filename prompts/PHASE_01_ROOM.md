# Antigravity Prompt — Phase 0 and 1

Read `AGENTS.md` and all files in `spec/`.

Inspect the repository. Implement Phase 0 and Phase 1 only.

Build a genuinely playable 3D room using React, TypeScript, Vite, Three.js, React Three Fiber and Drei.

Required:
- Room shell and furniture.
- Third-person avatar.
- WASD movement.
- Mouse orbit camera.
- Smooth follow camera.
- Collision with walls and major furniture.
- Shift run.
- Mobile joystick.
- Touch camera controls.
- Responsive UI.
- Loading and error states.

Use procedural geometry if external assets are unavailable. Keep components modular.

Run the app, inspect it in a browser, test movement and collisions, run typecheck and production build, and fix errors.
